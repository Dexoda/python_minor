# Python Minor - Лабораторные работы 6-9

## Быстрый старт

### Установка зависимостей
```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### Запуск в VS Code
1. Откройте папку: File → Open Folder → выберите `python_minor`
2. Установите расширение "Jupyter" от Microsoft
3. Откройте любой `.ipynb` файл
4. Нажмите "Run All" или `Shift+Enter` для каждой ячейки

### Запуск в Jupyter Notebook
```bash
cd python_minor
jupyter notebook
```

## Структура проекта
- `6/` - Лаба 6: Merging DataFrames
- `7/` - Лаба 7: Plotting Data
- `8/` - Лаба 8: Time Series
- `9/` - Лаба 9: Advanced Pandas

## Важно
Всегда запускайте ноутбуки из корневой папки `python_minor/`
